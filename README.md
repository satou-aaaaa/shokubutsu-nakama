# 植物なかま分け（shokubutsu-nakama）

植物の名前と様子を見て、植物の5つのなかま（単子葉類・双子葉類・裸子植物・シダ植物・コケ植物）のどれかを当てる1日5問の学習ゲーム。正解したら「種子は？」（胚珠が子房の中・胚珠がむき出し・種子をつくらない）も選ぶ。ソテツ・スギナ（つくし）・イチョウなど、まちがえやすい植物も出る。

遊ぶ: <https://satou-aaaaa.github.io/shokubutsu-nakama/>

- 中身は大阪府教育委員会「中学1年理科 7 植物のなかま」「6 植物の体のつくりと働き①」のプリント（解答）で確かめたことだけです。
- くわしくは教科書や、植物の図鑑で確かめてください。
